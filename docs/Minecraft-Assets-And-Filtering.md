# Minecraft 方块库、版本与筛选

## 1. 数据来源与边界

当前仓库**不包含任何 Minecraft 原版贴图或受版权保护的资源**。

内置方块库 `core/materials.py::MC_BLOCKS` 只包含：

- 方块 ID（Java 命名空间风格，如 `white_concrete`）
- 中文显示名
- **屏幕近似 RGB**
- 类别、获取条件、可再生、成本等级
- 引入版本、重力/透明标记、可建造标记
- 来源标记 `builtin-approx`

界面明确提示“内置色值为屏幕近似，未加载真实版本贴图”。预览是“纯色近似渲染”，不是真实贴图预览。

## 2. 版本与筛选

- 版本列表：`1.12.2`、`1.16.5`、`1.20.1`、`1.21.4`。
- 版本比较采用结构化数字元组，不使用字符串比较。
- 每个方块记录 `introduced`（如深板岩 1.17、黑石 1.16），旧版本会自动排除新方块。
- Java/基岩版均出现在 `editions` 字段中；**当前内置库两版本共用同一元数据**，版本差异未做真实资源验证。

筛选维度相互独立：

1. 材质类别：混凝土、羊毛、陶瓦、带釉陶瓦、木板、原木、石头、砂岩、泥土、玻璃、矿物/金属、下界、末地、自然材料。
2. 获取条件：不限制 / 生存可获取 / 仅可再生。
3. 成本偏好：不限制 / 低成本优先（tier ≤ 1）/ 中等成本上限（tier ≤ 2）。成本等级是内置可配置规则，不是客观统一价格。
4. 建造限制：仅完整可建造方块（内置数据中全部为完整方块；空气/流体/技术方块未收录）。

UI 中类别多选为“交集”语义；不勾选表示全部。每次映射后反向核对每个单元都属于最终候选集，`legal_rate` 必须为 100%。

## 3. 颜色匹配

1. 源图采样为逻辑网格（块均值）。
2. 候选方块转换到 Lab(D65)。
3. 网格颜色在 Lab 空间做最近邻匹配（分批计算，避免 N×K 大数组）。
4. 生成 `PaletteEntry` 与 `MaterialRef`，ID 为方块 ID。
5. 统计使用种类、方块总数、候选数、平均/P95 CIEDE2000 色差。

直接材料匹配是默认基线；基准显示它优于“先 K-Means 再映射”（见 `docs/Clustering-Benchmarks.md` 第 5 节），因此 MC 模式不强制预量化。

## 4. 用户资源包导入

支持 Java 版资源包 ZIP（只读）：

- 只扫描 `assets/minecraft/textures/block/*.png`，按文件名匹配内置方块 ID。
- 不落盘、不执行包内脚本、不读取其它路径。
- 限制：最多 5000 个成员、单贴图 8 MB、解压总量 200 MB。
- 拒绝绝对路径、`..`、盘符路径。
- 对贴图可见像素求平均 RGB（忽略全透明像素），用于匹配与纯色预览。
- 覆盖来源标记为 `user-resource-pack`，统计中显示覆盖数量。

限制：

- 只使用平均色，不支持多面贴图、生物群系染色、旋转原木端面、玻璃叠底、发光/水浸等机制。
- 不支持模型/方块状态解析、Bedrock 资源包结构差异。
- 资源包冲突优先级未实现。
- 导入的贴图只在内存中使用，不写回、不上传。

## 5. 统计与导出

- 材料统计：总方块数、方块种类、各方块数量、候选集大小、合法率、平均/P95 色差。
- 导出：PNG（纯色预览）、CSV（方块 ID/名称/十六进制/数量/来源）、PDF 图纸（网格坐标、方块简写、图例）。
- 未实现：`.schem`/`.litematic` 结构文件、地图画子模式、按区块的建造成本估算。
