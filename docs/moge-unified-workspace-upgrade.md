# Moge 2.0 三模式统一工作台升级报告

## 1. 执行结论

本轮以拼豆模式为参考，把坐标尺、5/10 格辅助线、格内标记、图例面板、材料详情、颜色定位高亮、图纸导出、工程保存等能力抽取为共享层，并接入普通像素、Minecraft 方块画和拼豆三种模式。

结论：**已经达到“统一三模式像素艺术工作台”的功能目标**。三种模式共享同一套视图、图例、编辑、工程与导出交互；各自保留独立处理算法、材料数据库、筛选条件和工程内容。仍存在的限制见第 11 节。

本轮未使用 GitHub 旧版代码覆盖本地工程，未清理或回退已有未提交修改。Git 工作树中原本存在的 `README.md`、文档与测试文件改动均保留。

## 3. 共享组件设计

### 3.1 `ModeAdapter` 适配层

`core/workbench.py` 定义统一接口：

- `prepare_entries()`：为条目补齐 `code`、`cell_code`、`abbrev`、`symbol`，不改变材料本身。
- `legend_payload()`：生成图例条目显示数据，字段包括主行、副行、数量、占比、色块、透明/特殊状态、贴图路径。
- `tooltip()`：生成图例悬浮说明。
- `details()`：生成材料详情 HTML。
- `browse_entries()`：无作品时返回当前模式可浏览的候选调色板。

三个适配器：

- `PixelAdapter`：调色板编号 `#001`、HEX、RGB、符号、锁定像素数；无作品显示 16 色参考调色板。
- `MinecraftAdapter`：方块 ID、名称、版本、类别、状态、可见面、符号、真实贴图缩略图；无作品显示当前版本的合法候选方块。
- `BeadAdapter`：品牌、系列、色号、名称、材质、符号、数量与占比；无作品显示当前品牌/系列全部色卡。

图例排序、搜索、范围切换只作用于统一条目列表，不再在 UI 里分别写三套逻辑。

### 3.2 共享图纸显示面板

原拼豆“施工图显示”组移动到 `_build_view_panel()`，位于模式面板之外，始终可用：

- 视图：成品预览 / 施工图 / 图例统计 / 黑白打印。
- 格内显示：纯颜色 / 色号 / 缩写 / 黑白符号 / 混合。
- 坐标数字：每格 / 每 5 格 / 每 10 格。
- 分区宽高：拼豆默认 29，Minecraft/像素默认 16，可改 16/32 等。
- 显示网格、X 轴、Y 轴、坐标数字、5/10 格辅助线、分区、透明空白格。
- 颜色/编号/符号标记开关。
- 成品预览 / 施工图 / 黑白打印预设。

每个模式在 `mode_settings[mode]["view"]` 中独立保存显示状态，切换模式不会串用视图参数。

### 3.3 图例面板复用

继续使用 `LegendItemDelegate`，新增能力：

- MC 条目优先绘制真实方块贴图缩略图，缺失时回退色块。
- 统一字体层级、行高、内边距、省略与多列自适应。
- 当前排序、搜索、已用/全部切换、图例 PNG 导出全部保留。
- 右键菜单：查看材料详情、锁定该颜色、解锁该颜色。
- 单击图例条目会在画布上用金色描边高亮该材料的所有使用位置。

### 3.4 统一数据与空单元格

- 内部网格索引仍从 0 开始；坐标尺、悬停、定位、材料详情统一显示 1 基坐标。
- `labels = -1` 表示空白/透明格，所有模式共用 `apply_blank_mask()`。
- 白色像素、白色方块、白色珠子仍是真实材料，不等于空白格。
- 编辑、锁定、选区和撤销历史继续由 `GridDocument` 统一承载。
- 工程保存时三种模式都写入 `cells`、`symbols`、`labels` 与条目元数据；读取后恢复锁定掩码和统一标记字段。

## 4. 三种模式的差异

| 能力 | 普通像素 | Minecraft | 拼豆 |
| --- | --- | --- | --- |
| 处理算法 | 现有 K-Means/MiniBatch/Ward 等，不改数学语义 | 版本合法方块候选 + 颜色/纹理匹配 | 品牌/系列色卡最近色匹配 |
| 材料来源 | 聚类生成颜色或导入调色板 | Java/Bedrock 独立版本资源库 | SQLite 多品牌色卡 |
| 格内编号 | `#001` | 方块序号/缩写 | 真实色号 |
| 图例主字段 | 编号、HEX、RGB | 名称、方块 ID | 品牌、系列、色号 |
| 图例附加 | 锁定像素数 | 版本、类别、状态、可见面、贴图 | 材质、符号、可信度 |
| 分区默认 | 16 | 16（常用 16/32） | 29 |
| 专属设置 | 采样、目标颜色、聚类算法、调色板导入导出 | 版本、类别、获取条件、贴图、匹配策略 | 品牌、系列、库存、底板、每包数量 |
| 真实纹理 | 不支持 | 支持真实贴图预览与图例缩略图 | 不支持 |
| 空单元格 | 支持透明背景 | 支持透明背景 | 支持透明背景 |

模式专属设置仍位于各自面板：普通模式不显示拼豆品牌与底板采购，MC 不显示拼豆色卡库存，拼豆不显示 MC 版本/朝向。

## 5. 坐标、网格与图纸视图

- 所有模式支持 X/Y 轴、每 5/10 格辅助线、鼠标悬停坐标、定位、选中高亮、自定义分区。
- 显示坐标从 1 开始，内部数组保持 0 基。
- 坐标尺基于同一个 `_image_rect()` 推导，缩放、平移、窗口变化自动同步。
- 视图切换仅修改画布渲染与图例页显示，不重新量化、不改变 `GridDocument`。
- 图纸 PNG 与分区 PNG 使用实际 `labels`、`entries`、`symbols` 渲染，不读取屏幕截图。

## 6. Minecraft 模式

- 复用共享图例面板、坐标、辅助线、分区、导出。
- 图例显示真实贴图缩略图（已加载版本资源时）、方块名称、ID、Java/Bedrock 与版本、类别、状态、可见面、符号、数量和占比。
- 点击图例高亮所有使用位置。
- 右键查看材料详情；材料锁定/解锁。
- 当前版本合法候选约束保持不变；结果仍执行候选集反向核对。
- 分区默认 16，可配置 16/32 等，不与拼豆底板规则混用。
- 纯色/真实纹理预览切换保留。

## 7. 普通像素模式

- 复用坐标、辅助线、格内编号、符号、图例、统计、图纸导出。
- 图例显示编号、HEX、RGB、色块、像素数、占比、符号与锁定像素数。
- 新增调色板 CSV 导入/导出：
  - 导出：索引、名称、HEX、RGB、用量。
  - 导入：读取 `hex` 或 `r,g,b` 列，按 Lab 最近色整体映射现有网格，不重新聚类。
- 画笔、吸管、填充、橡皮擦、框选、锁定、撤销/重做保持原有逻辑。
- 右键图例可锁定/解锁该颜色的所有像素。
- 保留现有颜色聚类算法和画质参数，不因 UI 共用改变聚类数学语义。

## 8. 拼豆模式回归

- 品牌/系列/库存/禁用、色卡浏览、底板、采购包数、材质与可信度信息保持。
- 图例字体、间距、搜索、排序、多列、图例 PNG 导出保持。
- 坐标尺改为 1 基显示，内部数据不变。
- 空白格、白色珠子、透明材质统计保持。
- 原有拼豆测试与 GUI 截图继续通过。

## 9. 导出系统

复用 `exporters/bead_sheet.py` 与 `exporters/legend_sheet.py`，没有复制三份导出逻辑：

1. 高清成品 PNG：无坐标、无图例。
2. 施工图 PNG：X/Y 轴、辅助线、分区、编号、图例。
3. 黑白符号 PNG：白底、唯一符号、符号图例。
4. 图例 PNG：当前搜索、范围、排序下的全部图例。
5. 分区 PNG：按当前分区规格逐区输出，坐标保留全局行列号。
6. PDF：保留单页版式接口；按分区自动分页尚未接入 UI。

所有图纸读取实际网格与材料统计。

## 11. 未完成事项与限制

1. **PDF 分页**：当前 PDF 仍为单页缩放版；分区 PNG 已完成，按分区自动生成多页 PDF 尚未接入 UI。
2. **全局替换入口**：现有“替换同类”工具可完成全局替换；图例右键尚未提供“一键选择替换目标”的专用对话框。
3. **逐格数据规范化**：`cells` 同时保存稳定材料引用和导出所需的解析字段；尚未完全改为只存引用、全部由图例数据库解析。
4. **MC 特殊材质**：生物群系染色、半透明、朝向面等仍按既有近似规则处理，限制说明保持。
5. **像素无作品调色板**：普通像素没有固定候选色卡，未生成作品时显示 16 色参考调色板，不代表实际聚类结果。
6. **调色板导入语义**：导入按 Lab 最近色映射，不保留原颜色身份；导入后清空撤销历史，避免旧索引与新调色板不兼容。
