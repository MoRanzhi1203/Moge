# 拼豆图纸视图优化与施工图增强

本轮在现有拼豆模式、多品牌色卡库和编辑/导出链路上，完成了从“像素预览”到“可制作施工图”的升级。所有视图切换只改变渲染，不重新量化；逐格数据、图例统计和底板分区均来自同一份工程模型。

## 2. 画布坐标系统如何实现

坐标系统集中在 `ui/canvas.py`：

- 画布在绘制图像前通过 `_ruler_margins()` 预留顶部/左侧坐标尺空间；`_image_rect()` 的居中位置随边距偏移，因此图像、刻度、辅助线共用同一个网格矩形。
- `cell_rect(col, row)` 返回单元格在控件内的真实矩形；所有坐标刻度由同一个矩形推导，缩放手势和平移只改变 `_image_rect()`，刻度自动同步，不存在独立缓存导致的错位。
- `axis_tick_positions(axis)` 返回 `(格号, 像素位置)`，标签定位在格子中心；`guide_line_positions(axis, step)` 返回格边界位置。
- 编号步长由“每格 / 每 5 格 / 每 10 格”设置控制；格子过小时自动降级为 5 或 10 格，避免文字重叠。
- 坐标编号沿用工程内部 0 基索引，与“定位坐标”、状态栏 `(x, y)` 和编辑工具保持一致。

自动化测试 `test_canvas_axis_alignment_and_guides` 验证了：

- 每个 X 刻度的像素位置严格等于 `rect.left() + (index + 0.5) * cell`；
- 每 5 格辅助线位置为 5/10/15 格边界；
- 每 10 格辅助线位置为 10 格边界。

## 3. 格内标记如何实现

画布支持五种格内显示方式：

| 模式 | 行为 |
| --- | --- |
| 纯颜色 | 只绘制真实色块 |
| 色号 | 缩放足够时绘制品牌色号 |
| 缩写 | 绘制 `code` 前 4 位或名称缩写 |
| 黑白符号 | 为每种颜色分配唯一符号，适合黑白打印 |
| 混合 | 放大显示色号；中等缩放显示缩写；更小时回退纯色 |

实现要点：

- 条目在拼豆映射阶段写入 `meta["symbol"]` 与 `meta["abbrev"]`，画布只读取元数据，不从调色板下标反推。
- 符号由 `core/beads/pattern.py` 的 `symbol_for_index()` 生成：数字、大小写字母与符号共 69 个基础符号；超过后追加序号，220 色仍保持唯一（测试覆盖）。
- 文字颜色根据格子颜色的亮度自动切换黑白；只绘制当前视口内的格子，避免 256×256 全量重绘。
- 视图切换、显示模式切换、坐标开关均只修改画布配置，不触碰 `labels`、`entries` 或统计。

## 4. 图例面板如何重构

右侧原“调色板”已改名为“图例”，每个条目使用两行布局：

- 第一行：`色号 名称  ×数量（占比）`；未使用颜色显示“未使用”。
- 第二行：`品牌 · 系列 · 材质 · 符号`。
- Tooltip 额外提供完整 ID、可信度、许可/来源、RGB 数量等。
- 单个条目固定为 44px 高度，图标为真实色块。

面板能力：

- **已用颜色 / 全部颜色** 切换；无图片时自动展示当前品牌/系列的全部色卡，并保留“仅预览”提示。
- **排序**：用量降序、色号排序、色相排序、明度排序、名称。
- 搜索覆盖品牌、系列、色号、名称与 ID。
- 面板顶部显示当前范围、色数、已用色数与总颗数。

图例统计另有独立中心页面（视图 = 图例统计），内容与右侧统计共用 `_bead_detail_html()`，包括总颗数、空白格、白色珠子、透明/特殊材质、作品尺寸、采购包数、逐色号占比表和各底板分区数量表。

## 5. 空白格与白色珠子如何区分

区分贯穿数据、渲染、统计和导出四层：

1. **数据层**：`labels = -1` 表示空白格；白色珠子是真实调色板条目，例如 `W01 / 白`，有 `bead_id`、`code`、`rgb`。`build_cells()` 为空白格写出 `is_empty=True`、`bead_id=""`，白色珠子写出 `is_empty=False`。
2. **透明输入**：`sample_alpha()` 按格计算 alpha 覆盖率；拼豆映射在 `keep_blank_cells=True` 时把覆盖率低于阈值的格子置为 `-1`。因此透明背景进入拼豆模式会保留空白格，而不是合成白底后误判为白色珠子。
3. **渲染层**：拼豆预览对空白格输出 alpha=0；画布显示棋盘格，空白格与白色珠子仍可通过底纹区分。黑白视图里白色珠子有符号，空白格无符号。
4. **统计层**：`bead_summary()` 只统计 `labels >= 0` 的格子为珠子；空白格单独计数。白色珠子通过“名称含白且 RGB 接近白色”的规则单独统计。
5. **导出层**：空白格绘制浅灰棋盘底纹且不绘制色号/符号，不会冒充白色珠子；PNG 透明背景选项可进一步保留 alpha。

GUI 透明图验证结果：36×36 网格中总珠子 638 颗、空白格 658 格（638 + 658 = 1296），空白格未被计入总颗数。

## 6. 视图模式与“不重新量化”

拼豆模式新增四种视图，工具栏和左侧面板均可切换：

- **成品预览**：关闭坐标尺、辅助线、底板和标记，只保留色块。
- **施工图**：打开 X/Y 轴、坐标数字、细网格、5/10 格辅助线、底板分区和色号。
- **图例统计**：中心切换为图例统计页，显示尺寸、总颗数、色号清单和底板表。
- **黑白打印**：白底 + 唯一符号 + 网格，适合无彩色打印机。

当前视图同步显示在工具栏下拉框、左侧“施工图显示”组和状态栏“视图：…”。预设按钮（成品预览 / 施工图 / 黑白打印）只更新显示配置。

自动化测试 `test_view_switch_does_not_reprocess` 在处理完成后连续切换四种视图，断言：

- `_task_counter` 未变化；
- `results["beads"]` 仍是同一对象；
- `labels` 数组逐格不变。

## 7. 底板分区

- `board_regions()` 按底板规格生成区域，编号为 `A1、A2、B1、B2…`；列号从 1 开始，行号从 A 开始，超过 26 行自动进位。
- 画布绘制橙色底板边界与编号标签；`board_stats()` 统计每块底板的珠子数、空白格和颜色数。
- 底板宽高变化只更新分区显示和统计，不触发管线重算。
- 导出施工图时复用同一套 `board_regions()`，PNG/PDF 中绘制边界和编号；后续按底板分页可直接复用。
- 测试覆盖 60×60、29×29 规格下 9 个分区（A1–C3）的边界和编号。

## 8. 工程模型与保存/读取

`PixelGrid` 新增：

- `symbols: dict[str, str]`：条目 ID → 唯一符号。
- `cells: list[dict]`：逐格结构，字段包括 `x`、`y`、`bead_id`、`brand`、`series`、`code`、`name`、`rgb`、`hex`、`symbol`、`is_empty`、`material`、`transparent`、`special`、`locked`。

工程文件 `manifest.json` 的 `grid` 节点同时保存 `labels`、`symbols`、`cells`、`entries`。保存时重建 `cells`，确保编辑后的色号、空白状态和锁定状态落盘；读取时恢复 `symbols`/`cells`，`GridDocument.from_result()` 从 `cells` 还原锁定掩码。

Schema 版本保持 1，新增字段为可选字段，旧工程仍可读取；没有 `cells` 的旧工程会在下次保存时自动生成。

自动化测试 `test_project_roundtrip_preserves_cell_metadata` 验证：

- 保存/读取后 `labels` 完全一致；
- `cells` 数量等于网格格数；
- 非空格子的 `code` 与条目元数据一致、`symbol` 与符号表一致；
- 空白格 `bead_id` 为空；
- 锁定格 `locked=True` 被保留。

## 9. 导出能力

当前已实现：

- **高分辨率成品预览 PNG**：无坐标、无图例，浅色棋盘标识空白格，白色珠子保持纯白。
- **施工图 PNG**：X/Y 轴、坐标数字、5/10 格辅助线、底板边界、逐格色号、图例、总颗数与材料统计。
- **黑白符号 PNG**：白底、黑框、每色唯一符号、符号图例，可直接黑白打印。
- **单页 PDF**：复用同一套 `BeadSheetOptions` 与 `render_bead_sheet()`，通过 `QPdfWriter` 输出。
- 文件菜单新增三个独立入口：导出成品预览 PNG、导出施工图 PNG、导出黑白符号 PNG；原“导出 PNG”在拼豆模式下会按当前视图自动分派。
- 导出参数（坐标、辅助线、底板、色号/符号、图例）与界面显示开关一致。

未完成：

- 按底板自动分页的 PDF 尚未替换旧 `blueprint_pdf.py`；当前 PDF 为单页缩放版。
- 导出单元格像素尺寸尚未暴露到 UI，当前固定为成品 24px、施工图 20px、黑白 22px。

## 11. 剩余问题

1. **PDF 分页**：目前仅提供单页 PDF 渲染；按底板分页、每页独立图例与页码仍待接入 UI。
2. **坐标基数**：施工图编号沿用 0 基索引；若后续需要实体图纸常见的 1 基编号，需要统一调整定位、PDF 和测试。
3. **白色珠子识别**：`bead_summary()` 用“名称含白 + 接近白色”判定白色珠子；若某些品牌白珠显示名不含“白”，需要改用品牌白名单或材质属性。
4. **全部颜色范围**：有处理结果时，“全部颜色”指当前候选色卡（受品牌/系列/库存/禁用条件约束），不是跨品牌全局色卡；无结果时才是当前品牌/系列全部色卡。
5. **格内标记阈值**：为保证可读性，色号/符号在过小缩放级别自动隐藏；导出时按单元格像素自适应，未提供逐级阈值设置。
6. **超大网格导出**：单张 PNG 受 `max_pixels=20000` 限制；超过时提示降低单元格像素或按底板分区导出，分区自动导出尚未实现。
